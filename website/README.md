## 🚀 How to Host This Website (Free & Instant)

This folder contains a complete, zero-dependency, ultra-fast static website ready to be hosted on any platform in under 60 seconds.

### Option 1: Netlify Drop (Easiest - 10 Seconds)
1. Go to **[https://app.netlify.com/drop](https://app.netlify.com/drop)**.
2. Drag and drop the `website` folder directly into the browser window.
3. Your site is instantly live with a free custom SSL domain!

### Option 2: GitHub Pages (Directly from your repository)
1. Once your repository `solana-agent-kit` is pushed to GitHub:
2. Go to **Settings** > **Pages** in your repository.
3. Under **Branch**, select `main` and set the folder to `/ (root)` or `/website`.
4. Click **Save**. Your site will be published at:  
   `https://y81252294-svg.github.io/solana-agent-kit/website/`

### Option 3: Vercel
1. Go to **[https://vercel.com/new](https://vercel.com/new)**.
2. Import your GitHub repository `y81252294-svg/solana-agent-kit`.
3. Set **Root Directory** to `website`.
4. Click **Deploy**.

### Option 4: Local Preview
To view the website on your local machine:
- Double click [index.html](file:///c:/Users/Admin/Documents/solana-agent-kit-2/website/index.html) to open in your default browser, or
- Run via terminal:
  ```bash
  npx serve website
  ```
